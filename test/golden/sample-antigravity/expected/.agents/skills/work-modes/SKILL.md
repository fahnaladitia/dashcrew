# Work modes

## Dev

- Code first; explain only when something is unclear.
- Read a file before changing it.
- Data layer: test first, and run the tests after every data-layer change.
- Priorities in order: it runs, it is correct, it is clean.
- No formatter, no lines outside the task, no commit.

## Research

- No edits and no new files.
- Cite `file:line` for every claim.
- When something is not there, say "not found"; never invent it.
- Answer three questions: does it exist, who calls it, what tests cover it.

## Review

- No edits: report findings, do not fix them.
