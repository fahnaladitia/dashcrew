## Where the knowledge goes

"Everything in the adapter" does not work for every row. `doctor` imports `adapters`, so a doctor check written in `adapters` would either import `doctor` (a cycle) or need a shared check type; and the checks use `Doctor`'s machine state (`PathEnv`, `Home`, `CodexHome`, the `agy` binary). So:

- **Rows about the files sync writes go into `adapters`**, as one registry (`internal/adapters/registry.go`) rather than interface methods, since `me` and `sync` need them without building an adapter. Each row has:
  - the constructor `AdapterFor` calls;
  - the skill folder `SkillFile` reads (`.claude/skills` or `.agents/skills`);
  - the guard minimum (`version.AntigravityGuardMinimum` for Antigravity, `version.GuardMinimum` for the others), which `sync`'s `guardMinimum` raises to over the profile's agents;
  - the `SKILL.md` format `SkillText` returns, which `me` used to pick with `if claude-code`.
- **Doctor rows become one table in `doctor`**, `agentChecks map[string]agentCheck`, each with:
  - `hook func(Doctor) Check` (also what `HookChecks` returns);
  - `machine func(Doctor, *omap.Map[string]) []Check`;
  - `alwaysOn func(Doctor, add func(string) bool)`;
  - `agentsMdLimit int`.

  Each agent's checks move from `doctor.go` into its own file (`agent_claude.go`, `agent_codex.go`, `agent_antigravity.go`). `doctor.go` loses about 350 lines, a first step of the roadmap's "split doctor by check family".
- **`me` rows become one table in `me`**, `personalAgents map[string]personalAgent`, with:
  - `homeFile func(Places) string`;
  - `repoFile string` (relative; empty for Codex, whose repo lines go into the home file's block);
  - `block bool` (Codex writes a marked block in a shared file);
  - `linksOwnSkills bool` (only Claude Code links the member's own skills).

  The `antigravity` flag of the personal template stays: it is template text, not a path.

`guard/malformed.go` `agentOf` stays where it is: it tells agents apart by payload shape, which is guard knowledge.

## Tests

- **Completeness, one test per table:** every `agents.All()` has an adapter (`AdapterFor`), a skill root and a guard minimum; every one has an `agentChecks` entry; every `agents.Personal()` has a `personalAgents` entry. These replace the two tests from #47 with stricter ones.
- **Goldens and transcripts unchanged:** `go test ./...` with no `DASHCREW_UPDATE_GOLDENS` is the behavior check for the move.
- Existing doctor and me tests keep running unchanged; a test that has to change means the move changed behavior.
