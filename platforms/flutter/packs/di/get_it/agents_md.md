## Dependency injection: get_it

{{#pack.di.injectable}}
- Registrations are generated by injectable: annotate the class (`@injectable`, `@lazySingleton`, `@singleton`, `@Injectable(as: Interface)`; third-party types in a `@module`) and rerun `build_runner`. `configureDependencies()` in `{{pack.di.container_file}}` runs before `runApp`. Never edit the generated `*.config.dart`.
{{/pack.di.injectable}}
{{^pack.di.injectable}}
- Register every new dependency in `{{pack.di.container_file}}`. A new dependency left unregistered is a high-severity review finding.
{{/pack.di.injectable}}
- App code registers everything once at startup and reads it with `{{pack.di.locator}}<T>()`; only tests register fakes, in `setUp`.
{{#pack.di.transitive_only}}
- `get_it` reaches the app transitively and stays out of `pubspec.yaml`. Never add it as a direct dependency.
{{/pack.di.transitive_only}}
{{^pack.di.transitive_only}}
- Never add, remove or re-version `get_it` in `pubspec.yaml` without asking.
{{/pack.di.transitive_only}}
