## Database: sqlc

- Write queries in the `.sql` files with `-- name: <Name> :one|:many|:exec` and run `sqlc generate`; never edit the generated Go files (`Code generated by sqlc. DO NOT EDIT.`).
- Commit the regenerated code with the query change, in the same task.
- Run several queries in one transaction with the generated `WithTx(tx)`.
