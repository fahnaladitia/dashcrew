# Onboarding

Before step 0 of each task, while the member is new:

1. When the project has knowledge (`.ai/knowledge/`), read `README.md` (the index) and the feature and repo pages for the task's area. Check every code pointer you rely on.
2. When `.ai/project.yaml` has `project.links`, read the "Across repos" part of the `branching` skill: which repos the task may touch, and that the dependency merges first.
3. Name the project's chain for the task's tier in one line, from AGENTS.md, and the guard rules the member is most likely to meet (commit, push and merge are theirs).
4. Tell the member in at most five lines what you learned and what you will need from them, then start step 0.

Never skip a step of the project's chain because the member is new, and never answer a product question from memory when a knowledge page covers it.
